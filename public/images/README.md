# Your images go here

Drop files with these exact names and they appear automatically — no code changes needed:

| File | Where it shows | Suggested size |
|---|---|---|
| `banner.jpg` | The wide banner across the top of the dashboard welcome screen | ~1600×500 (wide) |
| `logo.png` | Bottom-left of the banner (transparent PNG looks best) | ~200×200 |

Notes:
- `.jpg` / `.png` extensions matter — match the names above exactly.
- Until you add them, the banner shows a soft themed gradient and the logo
  falls back to the **HeyVanilla** wordmark, so nothing looks broken.
- For the **Mood board** widget and the **Vision board** page, add images from
  inside the app (paste an image URL) — those are stored per-account, not here.
